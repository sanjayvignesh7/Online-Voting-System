Secure & Accessible Digital Voting

A modern, accessible frontend demonstration of an electronic voting workflow. Built exclusively with HTML, CSS, and Vanilla JavaScript for college project presentation. Features dual-mode voting (Standard & Voice-assisted), mock identity verification, and instant ballot confirmation.

Voter ID Verification Mock authentication & duplicate vote prevention
Dual Mode Selection Standard UI & Voice-assisted accessibility demo
Instant Confirmation Verification receipt with mock transaction hash

* Notice: This is a college demonstration project. No real election or personal data is collected or transmitted.

Key Project Highlights

01
Voter ID Verification

Ensures that every voter provides a valid demo ID with client-side formatting checks.

02
Normal Online Voting

Clean, accessible digital ballot designed for standard laptop and mobile touchscreen inputs.

03
Voice Voting Demo

Simulates real-time speech recognition for hands-free and assistive accessibility workflows.

04
Accessibility Support

High contrast toggle, text resizing, ARIA tags, and complete keyboard Enter navigation.

05
Duplicate Vote Prevention

Prevents duplicate submissions under the same ID during an active demo presentation session.

06
Vote Confirmation

Explicit summary review step to prevent accidental mis-votes with simulated receipt hashing.

Technology Stack & Extension Roadmap

HTML5 Semantic Accessible Layout
CSS3 Custom Variables & Flex/Grid

Concept Expansion Roadmap (For College Presentation):

In a full-scale production system, this prototype architecture can be extended with:

  • Frontend: React.js, Vue.js, or Angular with TailwindCSS
  • Backend: Node.js (Express), Python (FastAPI/Django), or Go
  • Database: PostgreSQL, MySQL, or MongoDB with encrypted audit tables
  • Speech Processing: Web Speech API or OpenAI Whisper for production voice capture
  • Identity Verification: Optical Character Recognition (OCR) & Biometric/Face Match
